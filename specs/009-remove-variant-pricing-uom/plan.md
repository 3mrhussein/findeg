# Implementation Plan: Remove Variant Price Lists & Sellable UOMs

**Branch**: `009-remove-variant-pricing-uom` | **Date**: 2026-05-10 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/009-remove-variant-pricing-uom/spec.md`

## Summary

Remove the `variant_price_lists` and `variant_sellable_uoms` database tables and all related logic across the entire monorepo stack (database schema, types, seed data, backend domain/application/infrastructure, Dashboard UI, Storefront UI, and Cypress tests). The system simplifies to use the `product_variants` table's inline pricing columns (`base_price`, `strike_price`, `cost_price`) as the single source of truth for all pricing.

## Technical Context

**Language/Version**: TypeScript 5.7, Node.js 24  
**Primary Dependencies**: Next.js 16.2, Drizzle ORM, Zod 4, React 19  
**Storage**: PostgreSQL 16 (via Drizzle ORM, schema-push workflow)  
**Testing**: Cypress E2E, Vitest unit  
**Target Platform**: Web (Next.js SSR/SSG)  
**Project Type**: Monorepo (pnpm workspaces + Turborepo)  
**Constraints**: UOM was never active in production; no historical data preservation needed; docs must read as if UOM never existed (MVP)  
**Scale/Scope**: ~55 files across 4 packages + documentation
